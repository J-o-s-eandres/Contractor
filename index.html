How it works

Set up in 2 minutes.
Protects every PR. Forever.

01

Add one line to your CI/CD

No proxy. No agent. No infrastructure changes. One line in your existing GitHub Actions, GitLab CI, or CircleCI pipeline.

# .github/workflows/ci.yml
- name: Check API contracts
  uses: contractor/check@v1
  with:
    base: openapi/main.yaml
    candidate: openapi/feature.yaml
02

Contractor scans every PR automatically

On every pull request, Contractor compares your OpenAPI spec against the production version and catches breaking changes in milliseconds.

# What we detect:
✗ Endpoints removed
✗ Required params added
✗ Field types changed
✗ Required response fields added
✓ Non-breaking changes: allowed
03

Your whole team knows before it ships

Breaking change found? The PR is blocked, a detailed comment is posted, and the teams consuming that API get a Slack alert instantly.

✓ Build blocked (exit 1)
✓ PR comment → @frontend-team
✓ Slack #api-changes notified
✓ Markdown report written
# Full audit trail. Always.
